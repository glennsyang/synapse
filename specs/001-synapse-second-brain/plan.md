## Summary

Synapse is a modern second-brain application providing journaling, todo management, fitness/nutrition tracking, meditation routines, and visit tracking. Built with SvelteKit and SQLite, the app features cloud sync with offline capability, secure authentication, and a sleek responsive UI optimized for both desktop and mobile use.

## Technical Context

**Language/Version**: TypeScript (latest stable), Node.js 22.21.1  
**Primary Dependencies**: SvelteKit (full-stack framework), Svelte 5 (runes, no stores), Better-auth (authentication), Drizzle ORM (database with better-sqlite3 driver), Superforms + Zod (form handling/validation), Shadcn-svelte (UI components), Tailwind CSS (styling), TanStack Table (data tables), Resend (email notifications)  
**Storage**: SQLite with better-sqlite3 driver, UUIDs (v4) for all keys, cloud sync via fly.io volumes with offline-first architecture  
**Testing**: Vitest (unit/integration tests), Playwright (E2E - if needed)  
**Target Platform**: Web (responsive), hosted on fly.io  
**Project Type**: Web application (SvelteKit handles both frontend + backend via +page.server.ts)  
**Performance Goals**: <200ms page loads, <100ms form submissions, 60fps UI animations  
**Constraints**: Offline-capable with sync, mobile-responsive, single-user per account, last-write-wins conflict resolution  
**Scale/Scope**: Single-user productivity app, ~20-30 screens/views, expected <100k records per user  
**Code Quality**: Lefthook + lint-staged for git hooks, ESLint + Prettier

**Structure Decision**: SvelteKit provides a unified full-stack architecture, eliminating the need for separate frontend/backend projects. The framework handles both server-side rendering and API routes natively via `+page.server.ts` files. Route groups organize auth vs protected app sections. Better-auth generates its own `/api/auth` routes automatically. The `lib/server` directory contains server-only code that's never shipped to the client. Svelte 5 uses runes for reactivity instead of stores.
